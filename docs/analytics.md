# 运营数据中心（0.3.15 预览）

在「数据」下新增运营数据、分析与报表、采集管理三个分组，原「私信汇总」保留在消息管理分组。一级导航、64/240px双层侧栏、固定折叠按钮、环境列表和发布流程沿用原实现。

## 开始使用

1. 进入「数据 → 采集配置」，勾选抖音环境。旧自定义环境可点击「这是抖音账号」，仅保存数据采集模块的平台关联，不修改环境启动网址或图标。
2. 点击「立即采集」，在「数据采集任务」查看进度、各页面检查日志及错误原因。需要登录或安全验证时，到该账号官方后台完成，再重试。
3. 查看总览、账号、作品、趋势；报表页面按当前筛选导出 Excel 或 CSV。导出和看图只查询本地数据库，不触发网页采集。
4. 如需周期运行，设置频率后点击「开始定时采集」。默认不随软件启动自动恢复；可主动开启。电脑需开机、联网且软件保持运行。
5. 无法识别时，账号详情可导出脱敏采集诊断；需要详细网页证据时，使用已有开发者工具，选择对应环境录制官方数据页面，无需创建发布任务。

## 数据与真实平台验证边界

主要账号入口由用户确认：`https://creator.douyin.com/creator-micro/data-center/operation`。按需补充已知首页 `/creator-micro/home` 和作品管理 `/creator-micro/content/manage`。

适配器读取当前登录会话中可见的、明确标注的字段，不调用未公开接口、不提取认证凭据、不修改官网日期筛选、不点击作品或翻页。正式平台权限、真实已登录DOM及不同账号布局仍需实页核验；自动化窗口夹具只能证明读取/保存/展示链路及隔离，不能作为抖音真实账号验收。不能识别时显示失败/部分成功并导出结构诊断，不伪造成功。

| 数据 | 读取与计算口径 | 限制 |
| --- | --- | --- |
| 粉丝/作品/获赞总数 | 精确匹配「粉丝总数/粉丝总量/总粉丝数」「作品总数/总作品数」「获赞总数/总获赞」所在最小数字块 | 页面只写「粉丝」等模糊标签时需进一步核对，不猜数 |
| 周期播放、点赞、评论、收藏、分享 | 经营页明确标签和唯一完整绝对日期范围同时出现 | 只有「近7天」无法确认是否含今天；不猜周期、不修改官网日期；页面筛选必须与官方统计范围完全相同才展示 |
| 作品累计指标 | 当前加载作品列表的官方作品链接/作品ID及对应明确表头或字段标签 | 不翻页；只代表已加载作品，不代表账号全部作品，不将累计值冒充周期增长 |
| 作品身份 | 独立环境ID + 可靠官方作品ID | 同名不同作品分别保存；没有ID不按标题猜测；本地素材/发布任务关联字段预留为空 |
| 粉丝增长 | 周期起点前最后一次有效精确快照与周期内最后有效精确快照的差 | 缺少起点、约数或不兼容口径时无增长值；展示实际观察边界；允许负增长 |
| 作品数量变化 | 同上，累计作品数的快照差 | 删除/下架也会影响，不能视作新发布数量；暂不承诺全量新增作品统计 |

真实0与缺失、不支持、失败分别显示。万/亿等缩写保留「约数」精度，不拿约数求精确总和。失败保留最后有效值、时间和最新异常状态。跨账号求和要求相同定义、单位、周期及每个账号都有精确值；跨平台不混加播放/阅读/曝光。客户分组和未接入平台明确待开放。暂未提供作品缩略图缓存、全量历史回填、互动率、跨平台流量统一、自动下降诊断或PDF；无足够可靠资料时不计算这些指标。

## 存储、调度与隔离

数据位于原userData下 `analytics/analytics.sqlite`，独立于profiles.json、浏览器分区、发布库和私信库。包含指标定义、账号最新状态、历史快照、作品及作品历史、任务/日志、配置。每项有效指标含来源URL、定义、值、单位、精度、统计周期、采集时间；官方更新时间无法可靠取得时为null。SQLite备份使用`VACUUM INTO`，不覆盖已有文件。

同环境通过原发布调度器的`reserveReadOnly`互斥，与私信及发布共享。后台页面使用原Session，仅允许固定HTTPS数据页，拒绝弹窗和下载；关闭采集仅释放自有后台页面。账号忙时最多等待15秒；单轮账号总体限制65秒；临时加载失败最多重试一次，结构变化/验证不无限重试。单个页面失败时保留该账号本次其他页面有效数据，单个账号失败不影响其他账号。

定时周期5分钟–24小时，手动刷新不改到期时间，到期轮次合并且不重叠。软件重启后中断任务转人工检查，不自动重复不明任务。默认不自动恢复定时配置，需用户主动开启。取消、退出及删除环境会停止本模块活动并释放资源。账号、作品和任务每页50项，历史图表按北京时间观察日取最后一个实际点、最多500日；不补0，不宣称连接线代表未采集日的真实值。

报表仅保存至用户主动选择的本地位置，无自动上传。CSV/Excel对公式前缀文本做转义；报表包含真实账号名称/作品标题及环境ID供运营管理，分享前需自行检查隐私。单独采集诊断默认不包含这些字段、密码、Cookie、令牌、输入值和原始HTML。
