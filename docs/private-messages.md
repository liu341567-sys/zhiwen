# 私信汇总（0.3.12）

## 开源选型（2026-10-17 调研）

调研 GitHub 仓库元数据、许可证与公开 README 后，采用以下通用能力；不引入未经验证的私信采集、自动回复或凭据提取脚本。

SQLite沿用Node内置`node:sqlite`，不引入原生编译依赖；Node与SQLite遵循其各自许可条款，不笼统归为MIT。p-queue的完整许可保留于本目录的`third-party/p-queue-MIT.txt`，程序包也包含依赖自身许可。

平台DOM识别、账号互斥、基线比较、聚合提醒、错误退避和汇总界面为栖页自身模块。没有自建服务器、私信内容抓取或自动发送能力。

## 使用

进入“数据 → 私信汇总”，勾选需要监测的抖音预设环境，点击“立即巡检”先检查一个账号。点击“开始实时监测”后按周期持续巡检，默认2分钟、并发2个，可设30秒至1小时、并发1至4个。暂停立即终止当前读取并关闭临时后台页。重启默认不自动开始；需勾选“重启后继续监测”，且退出前仍处于监测中才会恢复。

官方入口由用户确认：`https://creator.douyin.com/creator-micro/data/following/chat`，用户确认“不点击具体对话不会清零”。监测只打开这个列表，绝不点击会话、发送、回复、标记已读或调用私有消息接口。官网自身可能改变行为，遇到不符合只读边界的平台变化应暂停监测。

同一环境使用原来的persistent Session；原页已经在列表时复用，否则创建短时后台列表页，读取后关闭。Cookie/localStorage/IndexedDB复用原Session；不复制Cookie至其他账号，不改变启动网址、绑定平台、原标签页或已输入草稿。浏览器原生sessionStorage属于标签页级别，后台页不会复制或覆盖原页的临时状态；如网站登录依赖该状态，显示待核实/需要登录，可在原环境手动打开列表后再巡检。发布或录制占用的账号跳过本次，发布调度与巡检通过账号读锁互斥；其他账号继续工作。

“查看消息”是明确的用户导航行为：打开/切换对应环境ID并进入官方列表，若已在列表不会重复打开。手动处理消息请在官网进行。

## 数量的含义

- 明确的私信总数或私信导航计数可以建立基线；不把系统通知或虚拟列表可见行的合计当成私信总数。用户确认官方只显示各会话旁的数字：对已加载会话读取未读徽标，默认显示“至少N，完整总数待核实”。只有ARIA明确证明所有会话均已加载时才可汇总为完整计数；不会点击或滚动会话列表去猜测总数。
- 官网若提供稳定会话标识，用本机随机盐与环境ID对该标识进行HMAC，仅在本地保存摘要及计数（最多每账号1000条，7天过期），不保存联系人、正文或原始标识。仅对同一已识别会话的计数增加进行估算提醒。新出现的会话仅建立基线，不把“新加载”误判为“新消息”。没有稳定标识、上限徽标或无法确认的结构不产生新增断言。计数方式切换时重新建立提醒基线，避免同一变化重复提醒。
- 首次有效读数只建立基线。此后只有可靠计数增加才提醒；相同计数不重复提醒。计数减少更新基线，不能证明期间没有新消息。
- 当前适配为“未读数量变化估算”，**不能提供精确新增消息数**。计数单位为条、会话或官网未注明单位，分开统计，不混加为条数。页面“本次新增”显示待核实，同时提供估算变化。
- 无数字、读取错误、登录过期、验证码、页面跳转、计数冲突不是零。99+等上限值只显示下界，不推进可靠基线、不据此发送新增提醒。错误时展示上次可靠基线的时间，不能作为当前未读。
- 同一轮多个账号增加合并为一次顶部浮层和一次Windows通知。声音遵循系统音量，未开系统通知时可用系统提示音；可分别关闭。通知失败不使巡检失败。

## 实际平台验证边界

入口与“列表不清零”由用户确认；开发环境无用户的已登录抖音会话。本版本对数字识别仍标示“实页待核验”，Windows测试使用官方origin下的合成页面，证明隔离、只读控制和状态处理，**不证明抖音当前网页一定具有对应计数**。没有明确数字将如实显示待核实，而非假装成功。

若一个账号显示待核实，可点击该行“详情 → 导出诊断”发送JSON。诊断只保留状态、探针名称、候选数量、受限结构类型、公开固定菜单标签及纯数字计数；不包含消息正文、联系人、密码、Cookie、令牌、输入值、请求/响应正文、查询参数或截图。所有数据本地保存，无自动上传。不能据此恢复私信内容。

## 数据与恢复

`用户数据目录/messages/messages.sqlite`单独存储设置、每环境可靠基线、最新结果、最多100条变化提醒、最多200条脱敏异常；不修改profiles.json或原发布数据库。WAL与FULL同步保证事务落盘，重启保留基线，避免重复提醒。异常按周期指数退避，最长1小时；“重新巡检”可忽略退避。点击“备份数据”生成一致的SQLite备份，使用新文件名；关闭软件后也可备份整个数据目录。

账号删除前停止该账号在途读取，后续清理关联巡检数据，不恢复已删账号。自动巡检不会切换导航；折叠状态、账号排序、搜索、已打开浏览器实例均保留。
