# 栖页操作录制与问题排查

开发者工具的简便模式只提供两个用途：**录制操作**与**排查问题**。都可以直接使用已有账号环境，**不需要创建发布计划**。普通开始录制不会运行、重试或提交发布任务。

## 录制完整流程或部分模块

1. 在栖页打开并登录要使用的账号，进入准备演示的页面。点击左侧「开发」→「打开开发者工具中心」，默认进入「录制操作」。
2. 选择账号，选择「完整流程」或「部分模块 / 某个步骤」，可填写名称，例如「抖音封面、位置与官方定时」。点击「开始录制，去网页操作」，工具先开启录制，再返回这个账号的原网页；未打开的已保存账号会打开原环境，不新建账号。
3. 像平时一样手动完成操作。工具记录点击、输入动作、文件选择、页面跳转及控件变化。输入值和文件路径不采集。可回到工具添加「模块 / 步骤」说明；例如开始设置封面、开始搜索位置、开始选择官方定时时分别标记。
4. 无关操作可点「暂停录制」，处理后点「继续录制」。暂停不会关闭页面或丢失此前资料。只录单个模块时，先在网页进入该模块，再开始录制即可。
5. 点底部「结束记录，整理资料」→查看预览→勾选可以分享→「保存 AI 资料包」。把 ZIP 上传到与 AI 的对话中即可，无需选择器或网页开发知识。

没有发布任务也能录制。录制不会自动点击任何网页按钮；作品最终提交由你的真人操作决定。已有账号的启动网址、平台绑定及登录数据不修改。自动任务正在占用账号时，须先暂停任务，避免人工与脚本同时操作网页。

## 记录失败现场，并演示正确操作

1. 点击「排查问题」，选择账号，描述哪里卡住。关联发布任务是选填；没有任务时同样可以开始记录。
2. 点「开始录制，去网页操作」；有关联任务时按钮为「开始记录当前现场（不运行任务）」，同时附带原任务的进度、错误和近期脱敏日志。
3. 点「记下问题现场」固定当前页面状态，再点「演示正确操作」，去原网页手动演示。关联任务时通过原引擎暂停同账号待执行与运行任务，再返回网页；无任务时只标记人工演示，工具不调用发布引擎。
4. 演示完成后结束、预览、保存 ZIP。资料中分别标注问题与人工纠正片段，供 AI 对照脚本和真实操作。

发布任务旁的「帮我排查」仍可用，会直接选择这个任务和原账号。「需要重新运行关联任务？」是可选的单独操作，沿用任务原有授权与计划时间，不扩大提交权限；已提交或结果不明确的任务保持防重复保护。结束只停止记录，不取消或恢复任务。任务被删除后仍可导出已保存的证据。

简便模式默认关闭截图，排除输入内容、Cookie、密码、令牌和本地路径。任务关联时包含最近 100 条脱敏日志。普通姓名等信息仍需分享前检查。可在「查看详细信息」中开启脱敏截图并逐张确认或删除；不需要截图也能导出完整结构化操作资料。

「新建记录」清空表单，保留上次本地报告。ZIP 包含 `report.json`、`report.md` 与离线 `report.html`；启用并审阅截图时包含 `screenshots/`。全程仅在本地保存，无自动上传，不自动修改或生成发布脚本。

## 可选：深入查看网页信息


点击右上角「查看详细信息」进入原专业视图；此步骤并非录制必需。工具直接连接已打开的账号环境，不另建浏览器、不修改启动配置或登录数据。左侧「开发」→「打开开发者工具中心」，在独立工具窗口选择环境并连接。需要操作网页时点击「在原窗口操作」，原环境和工具并行使用。

## 录制一次真实抖音流程

1. 在账号环境管理中打开已登录的抖音账号，进入创作者中心。
2. 连接该环境，查看「网页结构」中的真实页面和可交互控件。「元素检查」可悬停高亮、点击选取；选取点击不会激活按钮，选取后检查模式自动停止。
3. 如需截图，在「调试报告」主动开启脱敏截图。默认不开启；输入区、图片、视频、iframe、非白名单文本等会被遮盖。可增加排除区域的 CSS 选择器，也可关闭文本采集。
4. 点击「开始录制」，切回原网页，手动点击作品发布、选择视频、填写标题和简介、输入话题并用空格结束，以及执行你需要记录的操作。工具不会代替用户发布或选择话题。
5. 可暂停、继续、添加步骤说明。结束后检查「操作录制」时间线，删除无关步骤；「录制补充片段」在末尾追加步骤，不伪造历史时间或覆盖原操作。
6. 「页面变化」对比结构快照，查看新增、消失、属性、可见及启用状态变化。与历史报告对比会重新验证旧步骤的 CSS 定位器，显示零匹配或多匹配；零匹配也可能是尚未到达相同页面，不自动认定平台更新。
7. 检查所有截图，逐张确认可导出或删除。点击「预览导出资料」检查脱敏结果，再导出 ZIP。资料变更后必须重新预览。所有格式默认保存在你选择的本地位置，无自动外部上传。

可以将审阅后的 ZIP 提供给开发者，包含 `report.json`、`report.md`、离线 `report.html` 与 `screenshots/<截图ID>.png`。JSON 中操作、框架、定位器、前后快照、差异及脚本事件通过 ID 关联，截图无需依赖线上资源。JSON / Markdown 导出不包含图像数据，ZIP 和 HTML 包含已确认图像。

0.3.3 起 ZIP 对页面结构采用标准压缩，保留完整文件内容。如果聊天工具仍限制附件大小，可在电脑上解压，先提供 `report.json` 和 `report.md`；不需要重新录制。入口日志会标注控件位于导航、内容或菜单区域，帮助区分同名入口。

## 发布脚本调试

连接对应环境后，「脚本调试」显示发布引擎真实操作的开始、完成、耗时、目标和错误。可以刷新当前环境任务、暂停、继续或终止；沿用原有环境互斥、人工接管、授权与提交边界保护。无法确定是否提交的任务不能直接重复执行。

人工步骤与脚本定位对照按记录的选择器匹配，供开发者结合语义和页面状态检查；不是自动生成脚本或自动修复。网页结构工具不占用发布引擎的 debugger 连接。自动任务运行时禁止检查模式、手动高亮和遮盖截图；异常截图在任务释放环境后再采样，并保留实际截图时间，不能冒充错误瞬间的画面。

## 数据边界与已知限制

- 不采集输入值、密码、Cookie、存储内容、请求头、网络响应、任意 HTML 或本地文件路径。上传仅记录数量、类型和大小，标题、话题等输入内容可通过手动非敏感步骤说明补充。
- 页面文本经过邮箱、手机号、认证字段、不透明标识与 URL 查询参数脱敏。普通姓名等无法可靠自动识别，需使用额外排除区域、关闭文本采集、删除步骤或截图，并在导出预览中检查。
- 主框架使用私有隔离预加载连接，网站没有 IPC / Node 桥。子框架保持 `nodeIntegrationInSubFrames` 关闭，使用无权限的页面上下文进行 DOM / 事件采样；报告标记该来源，不把网页数据作为可信指令。无法访问的框架明确标记，不绕过网站权限。子框架快速跳转前的事件可能在下一次采样前丢失。
- 支持开放 Shadow DOM；关闭的根只标记，不能读取。CSS / XPath 需结合 `frame` 与 Shadow 根路径；XPath 不穿透 Shadow DOM。`frame-N` 是当前树位置，框架发生替换或重排后需要重新检查。
- 结构按约 900ms 采样，连续操作可能共用相邻快照，不保证每个输入按键均有独立截图。输入 / 滚动事件合并；页面关闭或导航销毁的不可访问帧会标记。截图超时、空图或超过安全范围不保存原图。
- 每报告最多 600 步、80 份结构快照、500 个近期脚本事件、20 张截图，单报告数据约 22 MiB；单框架默认最多 1200 节点，总采样约 2400 节点、最多 24 个框架。超过范围有提示并限制采样或保留最近资料，应及时导出。截图只采集原网页视口，不含浏览器地址栏或其他账号。
- 资料保存在软件数据目录 `developer-tools/developer.sqlite`。异常退出标记「已中断」，保留已保存资料，重启不自动恢复监听；报告可以加载、删除、追加录制。关闭工具释放网页监听与遮盖，不关闭原账号。

本地夹具和 Windows 自动化验证覆盖真实 Chromium / Electron 接口，不能替代用户已登录的真实抖音页面验收。请先录制一次人工流程，检查入口、上传与话题步骤完整性后再用于脚本维护。
