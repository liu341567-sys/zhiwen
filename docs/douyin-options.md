# 抖音官方位置与官方定时（0.3.10）

发布脚本复用原账号环境及网页控件，不读取认证凭据或另建账号系统。配置页不再实时访问官网、展示地点候选或提前上传准备视频。

## 地点配置

选择「固定地点 / 备选地点」，填写固定地点名称和完整地址；备选地点可不填，填写时需同时提供名称及完整地址。脚本上传任务视频后，在对应账号的官方控件中搜索固定地点，按名称和完整地址核对。未唯一匹配才尝试备选地点；两者均未准确匹配则转为需要人工处理，不按排序盲选，也不提交作品。

逐账号、逐视频覆盖放在「按视频 / 账号单独设置」折叠区域；优先级保持逐任务、逐视频、逐账号、批次默认。预览和详情显示固定及备选配置，执行日志、任务核验信息及导出记录说明实际选择地点及其来源。已经确认的配置是独立快照。

读取官方候选仅在脚本执行时进行；查询控件、结果加载、唯一匹配和选中状态均依据真实网页。搜索超时、控件变化、登录/验证异常暂停处理，不以备选地址掩盖页面或权限故障。原来的查询、选择、取消及进度 IPC 已移除。

## 视频与账号分配

- 「一个视频发一个账号」：视频按所选顺序循环分配给账号，每条视频只有一条任务。三条视频、两个账号得到 A、B、A 的关系。
- 「单个账号发布多个视频」：只能选择一个账号，全部视频按顺序交给这个账号。

不再提供全部视频发全部账号、随机配额及逐条多账号分发。已确认旧任务仍保留原关联；旧草稿含已取消的模式时回到配置步骤，需重新查看预览，不静默确认旧的多账号复制关系。

## 官方发布时间

只有三种发布方式：「立即发布」「抖音官方定时」「循环定时」。不再提供指定本地开始时间、每日本地执行时段或发布计划入口。新任务确认后直接进入上传队列，队列仍保留环境互斥、并发限制及同账号实际提交间隔；已保存旧任务的原执行计划不被提前或清空。

普通官方定时填写北京时间（Asia/Shanghai，精确到分钟），同账号后续视频按官方定时间隔顺延。执行时依据账号实际可用日期、时间范围和完整时间回读校验；提交前再次核对。文本输入不被官方控件保留时回退至已验证日历/时间控件。整体人工设置确认标记不能跳过官方定时核验。

「循环定时」选择日循环或周循环、开始日期和每日发布时间（每行一个 HH:mm）。周循环额外勾选星期几。例如七条视频、一个账号、日循环每日18:00，会生成连续七天各一条的官方时间；周循环选择周一、三、五和09:00，则依次填入这些日期。每天可以有多个时段。每个账号独立使用相同规则，按分到的视频数量安排；过去时段跳过，不无限循环或重复视频。

下一步把循环规则展开成每条任务的具体日期时间，预览中可在「设置」单独修改。确认后保存具体时间快照，执行时不重新计算。循环规则不代表平台无限允许排期：当前录制账号显示2小时后至14天内，其他账号以实际网页权限为准，超出范围会暂停而非改成本地定时。上传、处理、审核与实际上线仍由平台决定。

## 验证及保留能力

默认封面沿用平台设置；自定义封面仍需人工设置。自动提交继续需要明确授权；未授权则上传填写后暂停审阅。结果不明确时不自动重发。账号隔离、启动网址锁定、导航折叠、草稿、任务删除及开发者录制规则不变。真实已登录抖音的账号权限和网页仍需实机验证。
