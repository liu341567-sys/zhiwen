# 抖音官方位置与官方定时

0.3.8 使用现有环境的原网页及真实鼠标/键盘，不读取认证凭据，不建立另一套账号系统，不依赖自建服务器。

## 配置

视频向导的配置步骤新增“抖音官方定时”。官方日期使用北京时间（Asia/Shanghai），精确到分钟；批次同一账号的后续任务按配置间隔递增，不同账号单独计时。预览可逐任务修改或关闭官方定时。任务确认时固定保存，不随后续草稿改变。

本地计划表示开始上传，官方计划表示请求抖音安排的发布时间，两者独立；本地开始必须早于官方时间。执行时检查网页显示的账号范围、禁用日期和最终回读，电脑仍须在上传及提交时保持运行联网。平台审核、上传耗时及最终上线不能保证。

## 位置

选择“指定位置（官方搜索）”，填写搜索词、准确名称及完整地址。可以逐账号设置；逐视频和逐任务配置优先于逐账号，最后回退批次默认配置。同名候选无地址且无法唯一匹配时暂停，不按排序或鼠标坐标盲选。

“读取官方位置候选”直接连接选中的原账号。官方位置组件只在上传后的视频编辑页可用。账号仍在首页时，选择“地点查询准备视频”，点击蓝色“上传所选视频并读取地点”：明确上传本次选定的真实视频、仅用于查询，不提交作品，也不上传占位素材。已有编辑内容时不会覆盖；原账号需要登录/验证时暂停。已经有编辑页时可使用“读取已打开页面的候选”。选择会在原网页重新搜索并核实完整地址，再写入任务参数；执行正式任务时仍重新检查，以应对候选排序、账号权限及网页更新。准备上传保留原页面的私有证据，同一账号和视频任务核对后可复用，不重复上传；换文件、页面重建或手工编辑会使证据失效。当前任务分配了另一条视频时，只允许将已验证且未被编辑的查询准备页切换为新的上传页，既有其他草稿继续受保护。

另一个页面展示候选的机制是受控读取当前账号网页的公开 DOM 状态，通过本地 IPC 返回名称和地址；选择由原网页执行，并非复制 Cookie、伪造 GPS 或猜测平台内部 API。每个请求取得账号独占锁，任务引擎不能同时争夺同一网页。取消、切换条件或退出释放监听、标记与调试连接。

## 提交检查

官方时间优先按录制验证的可编辑输入框填写，失焦后等待回读；拒绝输入时再按网页月份、可用日期及小时/分钟值操作，不使用固定索引；重复时间滚轮选择最近且唯一的同值项，等选中模型稳定后关闭面板，回读完整字符串。地点按名称和地址匹配并等候候选面板关闭，监听用户对位置控件的后续修改。提交前任何不一致均暂停，不写“成功”。官方成功反馈只记录“已提交”，不等同审核通过或已上线。

默认封面保持平台默认。自定义图片、指定帧和裁剪尚未在本次录制中验证，继续人工设置。旧任务的人工确认路径保留；结构化官方时间不会被整体人工确认标记跳过，仍须通过真实控件回读。预览快照中已有时间时，最终确认请求遗漏字段不会静默关闭；明确设为null才关闭。提交授权、验证码处理及不明确结果禁止重复发布保持原规则。

## 验证范围

单元测试检查日期、时区、地址与查询格式、每账号时间间隔、任务快照、数据恢复和账号独占。Windows 原生测试用独立账号环境与本地 HTTPS 路由夹具复现实际控件，检查候选换序/同名、账号差异、原网页选择、滚轮延迟、月份切换、账号范围、禁用日期、人工干预、取消与资源释放，以及完整自动上传到提交流程。实际平台页面更新和账号权限仍需原账号实测；用户录制原文和真实地点不随源码发布。
