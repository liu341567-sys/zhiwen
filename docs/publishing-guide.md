# 内容发布中心 · 第一阶段预览

从一级「发布」进入。原账号环境、启动网址锁定、登录数据、拖拽排序及左下角折叠规则沿用。

## 配置一批视频

1. 「视频发布」导入 Windows 本地视频、文件夹或拖入文件，亦可选择已在素材库的记录。文件夹扫描当前层符合扩展名的文件；不复制视频。读取时长、大小、分辨率、格式、缩略图和 SHA256，识别相同内容。
2. 选择抖音。其他平台暂未开放；图文和文章仅保留页面框架。
3. 选择原有抖音环境，可以多选。旧自定义环境可由你明确关联抖音，仅保存在发布数据库，不更换原环境图标或启动设置。「已打开」不等于已登录，登录状态以最近五分钟实际发布页检查为依据。
4. 独立设置标题、完整话题组的固定、复用、顺序循环或随机洗牌规则，以及按视频 / 按任务匹配范围。选择全量、顺序均分、随机配额或逐视频指定账号。配置本地执行时段、每账号配额和最小间隔。
5. 在预览表修改、锁定、取消任务及调整顺序。重新匹配仅替换未锁定文案。锁定的文案及参数在返回修改配置后仍保留；“保存草稿”保存当前步骤与预览关联，重新启动可继续编辑。确认后每条任务保存独立快照，后续资源库变化不更改任务。

「立即」也遵守同账号最小间隔。日期与时段采用 Windows 本地时区。指定时间是开始上传与处理的时间，不保证作品准确上线时间；电脑需要开机、联网并保持栖页运行。

## 审阅、执行与接管

单任务“设置”中修改封面、定位及提交授权，只有点击“保存”才应用；关闭弹窗会丢弃该弹窗内的未保存改动。成功生成批次后，下一批回到素材选择步骤，视频、账号、标题、话题、封面、定位、执行时间、分发配置、单任务覆盖及提交授权全部重置；素材和文案库保留。可通过“清空当前草稿”主动重新开始，关闭清空确认弹窗则保留草稿。选择本地图片必须选中或导入具体图片，否则会提示修正并保留表单。

默认未勾选自动提交：系统尝试上传及填写后暂停，用户在原环境审阅。可在创建批次时明确授权各任务自动提交，或在任务详情中单独审阅并授权。

抖音主页识别“作品发布”，点击后按实际页面识别上传表单或“发布视频”菜单项；不点击“发布图文”。作品管理页继续支持明确的视频入口。等待过程中上传表单出现时直接继续；入口失败日志列出当前路径及候选，不含查询参数。

自动任务直接复用环境 ID 对应的现有 WebContentsView 和 Session；同环境一条、默认两个环境并发，可设置 1–6。执行中网页显示接管入口，地址栏导航、关闭和删除受执行权保护。账号环境还有未取消或结果未核实任务时，不允许删除，避免丢失人工核实上下文。

「人工接管」暂停本账号的待执行 / 执行中任务，回到同一个浏览器实例；其他账号继续。验证码、二次验证、登录失效、页面变化或不明确结果不会被绕过。完成处理后可继续、核实、取消或对未提交的失败任务重试，失败任务最多五次执行；人工审阅、平台设置及暂停后继续不受这个失败重试次数限制。

自定义封面、指定视频帧、定位及平台原生定时目前需人工在平台页面设置并核实，界面会明确提示。首次默认封面由平台实际生成。标题与话题分步骤输入，每个 `#话题` 后发送一次真实空格按键，由抖音编辑器自动转换；不选择候选框内容。核对时忽略占位与零宽字符、话题节点的渲染间距，候选框未结束仍会暂停。已核对的原任务在人工审阅后继续时不重复填写。真实平台是否建立话题关联仍需实机核实，不以文本显示代替话题 ID 验证。

预览与表单就绪后即可填写文案，不要求未填文案时“发布”按钮已经可用。预览可播放不等于网络上传完全结束；自动提交前还会核对当前相关上传 / 转码进度、平台按钮、文案与素材归属。若持续等待，日志每约 30 秒记录一次“上传状态检查”，包含完成提示、预览、输入框、进度及发布按钮状态，便于排查。暂停后继续不重复选择本任务文件。

在点击提交前，同步保存提交边界。提交反馈只标记「已提交」，不冒充审核通过或发布上线；无法确定的结果标记「结果待核实」，禁止自动重试。「核实尚未提交」需要你在平台检查后填写说明，才允许再次执行；「核实发布成功」记录人工核实说明与可提供的作品链接。

## 资源、记录与备份

素材库支持预览、搜索、批量移除索引、分组和文件检查。移除索引不删除原视频文件。任务执行前再次核对文件存在、权限、大小、修改时间和内容摘要；原文件改变后须重新导入。

标题与话题库支持分组、编辑、单条 / 选中 / 当前筛选删除、去重、排序、多行添加及 TXT / CSV / Excel 导入；资源类型还可切换到封面图片、常用定位进行管理。Excel 读取所有工作表第一列，不执行公式；每行一组话题。任务列表可按状态、平台、账号、日期、批次名称或素材筛选，按当前筛选或选择导出 Excel / CSV，包含快照、结果、重试次数和日志。

任务列表、发布计划和发布记录共享同一任务，可删除单条、选中记录或当前筛选记录，详情可删除整个批次；删除会同步移除该任务的本地日志，并清理空批次。未执行任务删除后不会执行，不删除平台作品或本地视频 / 图片。执行中的任务请先暂停；已提交、审核中或待核实任务请先人工核实。批量删除遇到受保护任务时整批拒绝，不会部分清理。已成功发布的任务删除可见记录后仍保留最小账号 / 素材摘要去重标记，重复任务确认仍需明确允许。资源记录删除不修改已确认任务快照。

发布数据库独立位于原用户数据目录的 `publishing/publishing.sqlite`，采用 WAL 与同步事务。程序退出先中止脚本并保存任务；重启后中断任务暂停，已到提交边界的任务待核实，错过计划时间五分钟以上的任务暂停。不会自动补发旧任务。每任务保留最近 1000 条日志，详情展示日志。页面右上角可导出一致性数据库备份，备份不包含原视频或浏览器登录数据。

## 验证边界

原生窗口与本地平台夹具验证上传、填写、授权提交、并发、环境复用、人工接管、数据库恢复及三档 DPR。真实抖音登录、页面结构、话题关联、账号权限、审核及作品上线尚需用户 Windows 已登录环境实测。不能把本地夹具通过描述为真实抖音已发布成功。

建议第一轮仅使用一个账号、一条自有测试视频，保持默认人工确认。查看任务日志；需要平台设置时接管原页面。核实实际上传、标题、话题和账号后，再启用自动提交与多账号批量计划。
