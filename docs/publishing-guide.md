# 内容发布中心 · 实时发布工作台（0.4.0）

进入一级「发布」→「视频发布」，默认显示左侧账号、右侧表单的工作台。直接使用已经建立的抖音账号环境，不需要重新创建或登录账号。

## 新工作台怎么用

1. 点击「添加账号」，勾选原有抖音环境。每个账号本期准备一条视频；多个账号可以同时准备。自定义环境如需关联抖音，可在「高级发布向导」中明确关联，不会自动根据网址猜测账号类型。
2. 左侧选择账号，右侧从本地或素材库选择视频。**选择即开始在这个账号的原官网上传**，不等待正式发布。视频仍保存在原路径，不复制登录数据。已有不属于本次工作台的官网视频草稿时，会暂停并提示处理，避免覆盖。
3. 填写标题、话题。停止输入约 400 毫秒后自动同步到原官网并回读核验；输入法组词期间不会发送半成品。话题输入 `#关键词` 后，本地显示该账号官网当前返回的候选，点击即可在原页面选择；也可在话题后输入空格，让官方编辑器确认话题。候选变化后旧选项失效，不能用旧候选点击新内容。
4. 要复用文案，勾选左侧账号 →「批量填写」，分别选择应用标题、话题。空白字段、锁定文案和已经确认的任务不会被覆盖。应用后立即同步各账号官网，不重新上传视频。
5. 等待各账号显示「官网已核验」，勾选要提交的账号，点击底部「正式发布」并确认。**此时只逐页点击已经准备好的官网发布按钮，不重新上传或填写。** 尚未就绪的账号可留在工作台继续修改，先提交其他已核验账号。
6. 在工作台或「任务列表」查看进度与日志。「已提交」只代表官网反馈收到提交，审核和上线仍由抖音处理。整批结束后点击「新建批次」开始下一批；原素材、发布记录和账号登录状态保留。

仅完成上传和编辑不会提交作品，正式发布需要你明确确认。同步中、候选未确认、官网内容变化或核验版本过期时，不能直接提交。发布按钮始终位于底部固定操作栏，右侧表单独立滚动。

## 异常、保存与人工接管

异常在对应账号的「人工操作栏目」显示，不要求重新配置所有账号。点击「人工接管」进入同一个官网页面，自动填写暂停，避免与人工操作冲突。处理后回到工作台，明确点击重新检查/继续同步。其他账号可以继续准备或提交。

工作台自动保存本地表单，切换导航不关闭已准备的原账号页面。重启后恢复账号、视频引用和文案，但不会假装上次网页连接仍然有效：需要重新核验原页面；无法证明视频归属时转人工，不偷偷重新上传或覆盖其他草稿。

已正式确认的账号参数固定为任务快照，不能再由批量填写修改。结果不明确的任务不自动重发，应先在任务列表核实。进行中的已确认任务结束或取消后，才可清空整批；移除未提交账号或更换视频会明确确认，并只释放本工作台拥有的官网草稿，不删除账号或本地文件。

本期新工作台只提供视频、标题和话题。封面、位置与官方定时后续逐步接入；需要原有能力时，点击页面顶部「高级发布向导」。该向导沿用原来的确认后排队上传方式，**与新工作台的实时同步方式不同**，两份草稿独立保存。

以下为保留的高级向导说明。0.3.10 已移除本地定时配置及「发布计划」入口；旧任务保留原计划。「循环定时」使用官方定时，日/周规则只为本批次素材生成具体日期，不重复发布素材。

# 高级发布向导

从一级「发布」进入。原账号环境、启动网址锁定、登录数据、拖拽排序及左下角折叠规则沿用。

## 配置一批视频

1. 「视频发布」导入 Windows 本地视频、文件夹或拖入文件，亦可选择已在素材库的记录。文件夹扫描当前层符合扩展名的文件；不复制视频。读取时长、大小、分辨率、格式、缩略图和 SHA256，识别相同内容。
2. 选择抖音。其他平台暂未开放；图文和文章仅保留页面框架。
3. 选择原有抖音环境，可以多选。旧自定义环境可由你明确关联抖音，仅保存在发布数据库，不更换原环境图标或启动设置。「已打开」不等于已登录，登录状态以最近五分钟实际发布页检查为依据。
4. 独立设置标题、完整话题组的固定、复用、顺序循环或随机洗牌规则，以及按视频 / 按任务匹配范围。分配只选择「一个视频发一个账号」或「单个账号发布多个视频」，设置固定/备选地点及立即、官方定时或日/周循环定时。其他匹配选项和单独覆盖位于折叠区域。
5. 在预览表修改、锁定、取消任务及调整顺序。重新匹配仅替换未锁定文案。锁定的文案及参数在返回修改配置后仍保留；“保存草稿”保存当前步骤与预览关联，重新启动可继续编辑。确认后每条任务保存独立快照，后续资源库变化不更改任务。

「立即」也遵守同账号实际提交间隔。所有官方日期及循环时段使用北京时间。确认后排队上传；完成官方提交前电脑需要开机、联网并保持栖页运行，提交后由平台处理官方定时和审核。

## 审阅、执行与接管

单任务“设置”中修改封面、定位、官方定时及提交授权，只有点击“保存”才应用；关闭弹窗会丢弃该弹窗内的未保存改动。成功生成批次后，下一批回到素材选择步骤，视频、账号、标题、话题、封面、定位、执行时间、分发配置、单任务覆盖及提交授权全部重置；素材和文案库保留。可通过“清空当前草稿”主动重新开始，关闭清空确认弹窗则保留草稿。选择本地图片必须选中或导入具体图片，否则会提示修正并保留表单。

默认未勾选自动提交：系统尝试上传及填写后暂停，用户在原环境审阅。可在创建批次时明确授权各任务自动提交，或在任务详情中单独审阅并授权。

抖音主页识别“作品发布”，点击后按实际页面识别上传表单或“发布视频”菜单项；不点击“发布图文”。作品管理页继续支持明确的视频入口。0.2.10 起，后台画面短时准备失败不会直接阻断点击；仍重新检查唯一目标、遮挡和真实页面变化。等待过程中上传表单出现时直接继续；入口失败日志列出当前路径及候选，不含查询参数。

自动任务直接复用环境 ID 对应的现有 WebContentsView 和 Session；同环境一条、默认两个环境并发，可设置 1–6。执行中网页显示接管入口，地址栏导航、关闭和删除受执行权保护。账号环境还有未取消或结果未核实任务时，不允许删除，避免丢失人工核实上下文。

「人工接管」暂停本账号的待执行 / 执行中任务，回到同一个浏览器实例；其他账号继续。验证码、二次验证、登录失效、页面变化或不明确结果不会被绕过。完成处理后可继续、核实、取消或对未提交的失败任务重试，失败任务最多五次执行；人工审阅、平台设置及暂停后继续不受这个失败重试次数限制。

0.3.10 简化地点设置：仅填写固定和备选地点的名称及完整地址，由脚本在上传后后台搜索，无法准确匹配时提示人工接管。配置页不读取实时候选、不提前上传查询视频。发布方式仅保留立即发布、抖音官方定时和循环定时；循环可按日或按周分配具体官方日期，预览确认后固定保存。视频分配只保留按账号顺序轮流分配和单账号全部视频，每条视频只有一条新任务。高级逐条/逐账号覆盖及文案库折叠展示。详见[官方选项使用说明](douyin-options.md)。自定义封面、指定视频帧仍需人工设置，默认封面由平台实际生成。标题与话题分步骤输入，每个 `#话题` 后发送一次真实空格按键，由抖音编辑器自动转换；不选择候选框内容。核对时忽略占位与零宽字符、话题节点的渲染间距，候选框未结束仍会暂停。已核对的原任务在人工审阅后继续时不重复填写。真实平台是否建立话题关联仍需实机核实，不以文本显示代替话题 ID 验证。

预览与表单就绪后即可填写文案，不要求未填文案时“发布”按钮已经可用。预览可播放不等于网络上传完全结束；自动提交前还会核对当前相关上传 / 转码进度、平台按钮、文案与素材归属。若持续等待，日志每约 30 秒记录一次“上传状态检查”，包含完成提示、预览、输入框、进度及发布按钮状态，便于排查。暂停后继续不重复选择本任务文件。

在点击提交前，同步保存提交边界。提交反馈只标记「已提交」，不冒充审核通过或发布上线；无法确定的结果标记「结果待核实」，禁止自动重试。「核实尚未提交」需要你在平台检查后填写说明，才允许再次执行；「核实发布成功」记录人工核实说明与可提供的作品链接。

## 待执行排查与本地页面记录

0.2.9 起，任务列表显示等待计划时间、账号占用、并发位置、人工核实阻塞或实际发布间隔，适用时同时显示可执行时间。原因变化会写入任务日志；详情显示调度器是否运行、最近检查时间和并发数量。未提交就失败 / 暂停的尝试不再占用新任务的发布间隔。旧版记录若已删除且无法判定是否提交，仍按保守间隔处理。

从工作空间直接进入发布中心也可初始化后台账号网页的真实非零原生视口，无需先人工打开一次。后台视图保持隐藏，继续使用对应环境 ID 的原实例、会话及登录数据；导航和人工接管规则不变。

为了定位真实平台的页面变化，可主动开启任务级本地诊断：

1. 任务列表 → 详情 / 日志 → “开始本地诊断”，然后开始 / 继续任务。
2. 自动流程等待或需要接管时，可进入原环境，按正常方式打开发布页、上传并填写；话题后按空格确认的事件也会记录。
3. 回到详情点击“刷新诊断”查看采样数量与页面 / 视口概况；可选择页面阶段并“保存阶段标记”，将手动看到的状态与时间对应。
4. “停止本地诊断”，再“导出诊断报告”保存 JSON。可将该文件作为附件提供给开发者；无需发送 Cookie 或登录信息。仅关闭详情不会停止记录，人工接管后也会继续。重新开始会覆盖本任务旧报告，请先导出需要保留的报告。

每 2 秒只读采样，最长 10 分钟，最多同时三个不同账号，报告最多 300 个状态快照和约 2 MiB，超限保留最新状态。记录 DOM 标签层级与位置、平台关键词、控件可见 / 可用状态、预览是否就绪、调度原因、执行阶段及点击 / 输入 / 话题空格事件类型。不会保存输入值、账号名称、Cookie、完整网址、媒体网址、HTML 或截图；不启动新浏览器、不跳转页面、不点击控件、不修改脚本，也不自动上传数据。平台重新导航后继续采样新页面。

报告和标记保存在发布数据库。软件重启后已保存报告可查看 / 导出，记录过程不会自动恢复。可单独“删除诊断”；删除任务时同步清理报告。数据库备份包含仍保留的本地诊断，与原视频及账号登录数据分离。JSON 用于对比自动流程和人工成功流程；不会自动学习或绕过平台验证。

## 资源、记录与备份

素材库支持预览、搜索、批量移除索引、分组和文件检查。移除索引不删除原视频文件。任务执行前再次核对文件存在、权限、大小、修改时间和内容摘要；原文件改变后须重新导入。

标题与话题库支持分组、编辑、单条 / 选中 / 当前筛选删除、去重、排序、多行添加及 TXT / CSV / Excel 导入；资源类型还可切换到封面图片、常用定位进行管理。Excel 读取所有工作表第一列，不执行公式；每行一组话题。任务列表可按状态、账号、官方日期、批次名称或素材筛选，按当前筛选或选择导出 Excel / CSV，包含快照、结果、重试次数和日志。

任务列表和发布记录共享同一任务，可删除单条、选中记录或当前筛选记录，详情可删除整个批次；删除会同步移除该任务的本地日志，并清理空批次。未执行任务删除后不会执行，不删除平台作品或本地视频 / 图片。执行中的任务请先暂停；已提交、审核中或待核实任务请先人工核实。批量删除遇到受保护任务时整批拒绝，不会部分清理。已成功发布的任务删除可见记录后仍保留最小账号 / 素材摘要去重标记，重复任务确认仍需明确允许。资源记录删除不修改已确认任务快照。

发布数据库独立位于原用户数据目录的 `publishing/publishing.sqlite`，采用 WAL 与同步事务。程序退出先中止脚本并保存任务；重启后中断任务暂停，已到提交边界的任务待核实，错过计划时间五分钟以上的任务暂停。不会自动补发旧任务。每任务保留最近 1000 条日志，详情展示日志。页面右上角可导出一致性数据库备份，备份不包含原视频或浏览器登录数据。

## 验证边界

原生窗口与本地平台夹具验证上传、填写、授权提交、并发、环境复用、人工接管、数据库恢复及三档 DPR。真实抖音登录、页面结构、话题关联、账号权限、审核及作品上线尚需用户 Windows 已登录环境实测。不能把本地夹具通过描述为真实抖音已发布成功。

建议新工作台第一轮仅使用一个账号、一条自有测试视频，先检查官网上传、标题和话题的同步，再明确确认正式发布。高级向导第一轮可保持默认人工确认；验证实际页面后再启用自动提交与多账号批量计划。

0.2.10 诊断会记录控件操作的具体阶段（目标检查、画面准备、悬停重检、按下、松开），不保存任意日志正文。出现“已完成上传及填写，当前为人工确认模式”表示尚未授权自动提交，是正常审阅步骤；它与入口识别失败不同。
