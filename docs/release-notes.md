# 栖页 0.2.5 · 发布确认、批次重置与记录管理

修复选择“本地图片”但未导入具体图片时，确认任务触发 SQLite 参数绑定异常的问题。配置与最终确认均校验封面资源，提示补选图片或改用平台默认首帧；失败时保留当前填写内容，不生成任务。

- 成功生成发布批次后，重置视频、账号、标题、话题、封面、定位、分发、执行时间、预览覆盖及授权等全部向导配置。素材与文案库及已确认任务保持不变。
- 增加“清空当前草稿”，确认后可随时从空白批次重新配置；正常切换页面、保存草稿和重启继续保留尚未提交的草稿。
- 任务列表、发布计划和发布记录新增单条、选中记录和当前筛选记录删除；详情可删除单条或整个批次，同时清理对应日志和空批次。
- 视频素材库增加明确的单条和批量删除记录入口。标题与话题库增加批量删除，并统一管理封面图片及常用定位的记录删除。
- 删除仅作用于本地索引和记录，不删除原视频、原图片或平台已发布作品，也不改变其他任务快照。
- 执行中任务需先暂停；已提交、审核中、结果待核实任务需先核实结果。批量删除采用事务，遇到受保护记录不会部分删除。删除成功作品的可见记录后仍保留账号与素材摘要去重标记，避免误重复发布。

原账号清单、浏览器会话、隔离、启动网址锁定、导航折叠、Logo 及配色不变。保留 0.2.4 上传等待修复和真实空格话题转换。封面、定位与平台原生定时仍需人工在平台设置，实际抖音页面能力以用户已登录 Windows 环境验证为准。

更新前正常退出旧版再安装，沿用原账号和发布数据库。旧版保留的配置可以通过“清空当前草稿”清除。详见[发布中心指南](https://github.com/liu341567-sys/zhiwen/blob/main/docs/publishing-guide.md)和[验证记录](https://github.com/liu341567-sys/zhiwen/blob/main/docs/validation.md)。
