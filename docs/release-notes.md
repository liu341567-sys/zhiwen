# 栖页 0.2.0 · 内容发布中心第一阶段预览

新增本地内容发布中心，延续双层导航、品牌蓝色、固定折叠规则与原账号环境隔离。

- 发布菜单分组为内容发布、发布管理、资源管理。视频发布采用五步向导，操作栏固定；图文、文章及其他平台保留明确的规划 / 暂未开放状态。
- 批量本地视频导入、文件夹扫描、拖入、缩略图、元数据、预览、分组、内容摘要去重与执行前文件检查。
- 原抖音账号环境选择、四种分发规则、独立标题 / 完整话题组匹配、文案库与 TXT / Excel 导入、可编辑任务预览及最终快照。
- SQLite 本地任务队列、每日多时段计划、账号间隔、默认两环境并发、同账号互斥、暂停 / 继续 / 取消 / 重试、人工接管、日志、记录导出及数据库备份。
- 抖音适配器从用户提供的作品管理入口识别上传页面，调用原浏览器环境的调试接口；不创建额外登录浏览器，不绕过平台验证。默认上传填写后人工审阅；自动提交需明确授权。
- 提交结果不明确时禁止自动重试，重启恢复保留快照并等待核实。

自定义封面、指定帧、定位及平台原生定时目前需人工设置。真实抖音网页、话题关联、账号权限与实际发布尚未通过已登录 Windows 账号验收，本版为预览版，不能视为所有第一期能力已经完成实机验证。本地计划表示开始执行时间，并非作品精确上线时间。

开发与自动化测试采用本地平台夹具，不发布真实账号内容。安装包的最终验证结果见 [验证记录](https://github.com/liu341567-sys/zhiwen/blob/main/docs/validation.md)，使用步骤见 [发布中心指南](https://github.com/liu341567-sys/zhiwen/blob/main/docs/publishing-guide.md)。更新前正常退出旧版，既有账号环境数据沿用。
