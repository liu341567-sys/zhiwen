# 栖页 0.1.1 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 修正浏览器标识中的中文应用名称，改用 ASCII 产品名 `Qiye`，保留真实系统、Chromium 和 Electron 标识及原生 Client Hints，避免网站编码 User-Agent 时出错。
- 修正临时网页存储的恢复范围：只在重新打开主标签页时，对每个网站来源恢复一次；网站已清除的临时值不会在后续导航中被反复补回。登录弹窗使用 Chromium 原生的窗口存储规则，不注入主标签页的旧快照，也不覆盖它。
- 修正启动恢复与用户操作的时序，避免恢复中的初始网址覆盖随后选择的网址。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

下载 `Qiye-0.1.1-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.1-x64.exe` 安装。`SHA256SUMS.txt` 提供两份下载文件的 SHA256 校验值。应用数据继续使用 `%APPDATA%\栖页`，更新前请正常退出应用并备份整个数据目录。

本发布流程要求 Windows 上的单元测试、语法检查和真实 Chromium 会话隔离测试通过后才生成发布文件。测试使用本地网页。本次修复处理已发现的浏览器兼容性和存储问题；尚未确认它们就是抖音「操作频繁」的原因，也未验证修复后真实抖音扫码、手机验证码及登录能够成功。本版本是试用版，安装包没有代码签名。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
