# 栖页 0.1.4 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 优化中性灰背景层次，首页欢迎区与卡片采用白色表面，清晰区分页面、内容和操作区域。
- 降低侧栏「新建环境」按钮的色块权重，使账号列表与工作区更突出。
- 品牌蓝集中用于主操作、选中提示和键盘焦点，保持重要操作易于识别。
- 统一按钮与列表的悬停、选中和危险操作反馈，使各区域的状态表达一致。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

下载 `Qiye-0.1.4-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.4-x64.exe` 安装，`SHA256SUMS.txt` 提供两份文件的 SHA256 校验值。更新前请正常退出旧版并备份整个 `%APPDATA%\栖页` 数据目录，已有账号环境继续沿用该目录。

本次为配色优化，账号数据、会话隔离和登录流程沿用原有实现；真实知乎、抖音登录兼容性仍需实机验证。Windows 发布流程要求单元、语法、真实浏览器隔离、本地登录兼容性、设备缩放界面及实际安装检查全部通过后，才交付发布文件。本版本为未签名的试用版。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
