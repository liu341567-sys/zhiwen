# 栖页 0.3.13 · 私信识别修复与简化界面

基于0.3.12修复私信会话角标读取失败：支持嵌套徽标去重、头像与重复会话行的结构识别，减少对特定行类名的依赖，排除导航通知及无关数字卡片。根据用户真实诊断中重复出现的4、1、16等徽标补充回归场景；原报告没有完整会话父层结构，因此不能把这些数字直接当作准确总数。

私信汇总默认仅展示开始/暂停监测、刷新一次、账号搜索和查看消息。频率、并发、通知、排序、备份与历史提醒统一收到“更多设置与使用说明”；每个账号的重新检查和诊断收入“更多”。无平台标识的旧环境可点“这是抖音账号”加入监测，不改动原网址、平台绑定或登录数据。

未读数字只代表官网可确认的数据；未证明列表完整时仍显示“至少”，失败显示“未能识别”，不虚报0或精确新增数。只读检查，不点击会话、不发送、不自动标记已读。继续复用原账号Session，不影响发布、导航折叠及账号排序。

验证使用实际Windows窗口与合成官网页面，覆盖用户报告呈现的重复角标形态、未知行类名、单会话与无关数字排除；用户的脱敏报告没有完整DOM，真实账号新版识别效果仍需在该账号确认。诊断新增不含联系人和正文的祖先结构信息，后续失败可在“更多 → 检查详情 / 诊断 → 保存诊断文件”导出。
