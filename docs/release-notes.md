# 栖页 0.1.10 · Windows 试用版

本轮分离全局功能导航和「我的环境」账号列表，沿用现有品牌视觉及账号数据。

- 新增 64 px 固定一级导航与 240 px 动态二级侧栏。环境管理保留搜索、新建、图标、编辑、删除与拖拽；一级菜单独立滚动，不挤压账号列表。
- 二级侧栏支持展开、收起与临时覆盖。收起后点击一级入口呼出覆盖菜单，外部点击、关闭按钮、Escape 或选择账号后关闭；「展开」恢复固定侧栏。覆盖不改变工作区或浏览器视口宽度。
- 模块切换复用原列表、图标与网页实例，保留选中、排序、搜索及滚动。布局偏好与窗口尺寸单独保存，退出前保存最后一次位置，重启恢复；临时浮层不跨启动保存。
- 发布中心预留视频、图文、文章、任务监控和发布记录，数据 / AI 同样预留入口。子功能标记「规划中」并禁用，不开发实际发布功能。
- 较窄窗口自动使用收起 / 覆盖模式，放大后恢复布局偏好。保留蓝色主按钮、固定头尾弹窗、启动配置锁定、顶部 Toast、删除位置保留与账号隔离。

临时覆盖时以当前网页的内存画面承接背景，网页实例继续保留，关闭后恢复实时页面；临时画面不保存或上传。界面配置使用独立文件，不修改账号清单结构、启动网址或浏览器登录机制，无需数据迁移。

本轮本地及 Windows 检查的实际结果见 [验证记录](https://github.com/liu341567-sys/zhiwen/blob/main/docs/validation.md)。Windows 安装及发布验收待完成，下载链接在成功后更新。

更新前正常退出旧版并备份 `%APPDATA%\栖页` 数据目录，原账号环境继续沿用。真实平台登录仍需 Windows 实机复测。
