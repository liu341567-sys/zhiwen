# 栖页 0.1.6 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 新建及编辑环境支持九个平台预设，以 3 × 3 选项直接选择创作者中心入口。
- 环境保存所选平台，选择项、侧栏与账号卡片使用对应平台图标；改名后继续保留关联。
- 同一平台可以新建多个独立环境，各账号继续使用各自的 Cookie 和网站存储。
- 支持自定义网址；编辑切换平台只更新启动入口，重新打开仍恢复上次页面和原有会话数据。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

下载 `Qiye-0.1.6-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.6-x64.exe` 安装，`SHA256SUMS.txt` 提供两份文件的 SHA256 校验值。更新前请正常退出旧版并备份整个 `%APPDATA%\栖页` 数据目录，已有账号环境继续沿用该目录。

本次增加平台入口与环境标识，登录流程和已有环境的恢复语义继续沿用；真实平台登录兼容性仍需实机验证。入口可访问或出现 401 / 403 都不表示登录问题已修复。Windows 发布流程要求单元、语法、浏览器隔离、本地登录兼容性、设备缩放界面及实际安装检查全部通过后，才交付发布文件。本版本为未签名的试用版。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
