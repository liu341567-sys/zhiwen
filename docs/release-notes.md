# 栖页 0.2.7 · 抖音主页发布入口修复

用户在创作者中心主页 `https://creator.douyin.com/creator-micro/home` 执行任务时，入口文字为“作品发布”，点击可进入发布页，展开菜单后还有“发布视频”“发布图文”。旧规则包含“发布作品”却没有“作品发布”，导致未找到入口。本版补齐该实际入口并处理后续视频菜单。

- 支持主页“作品发布”直接进入上传页，或打开菜单后仅选择“发布视频”。保留作品管理页及原有 SPA 视频入口。
- 分阶段检查真实页面状态：等待期间若上传表单已出现，直接继续，不再只等待入口按钮。已操作入口不会反复点击切换同一菜单。
- 多个链接明确指向同一个平台上传网址时可复用；不同目的链接不明确时仍暂停。过滤隐藏、透明、禁用及外部网址控件。
- 未找到入口时记录页面路径、上传控件数量、候选文字及路径，便于定位；不记录查询参数、账号页面正文或登录信息。
- 修复新导航的后台视图尚未建立渲染表面时点击未到达页面的情况：操作前等待小区域渲染，保持视图隐藏且不保存图像；发送真实悬停后重新核对控件位置。
- 按实时控件位置点击，不猜测发布 URL 或使用固定坐标。实际上传、文案、话题、提交授权和防重复逻辑沿用。

保留 0.2.5 的封面校验、完整批次重置、草稿清空和记录删除。原有账号环境、Cookie、登录状态、导航及品牌资源不变。更新前正常退出旧版再安装；“未找到入口”的未提交任务可继续执行，不需要重建账号环境。

验证采用原生 Electron 窗口及本地平台模拟页，不代表已使用用户真实登录账号验收抖音页面。详见[发布中心指南](https://github.com/liu341567-sys/zhiwen/blob/main/docs/publishing-guide.md)与[验证记录](https://github.com/liu341567-sys/zhiwen/blob/main/docs/validation.md)。
