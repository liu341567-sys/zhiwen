# 栖页 0.3.0 · 开发者工具中心

新增独立开发者工具窗口，直接连接已打开的原账号环境，支持真实 DOM 与交互控件分析、CSS / XPath 验证、开放 Shadow DOM、可视化元素选取、人工操作录制、结构差异与历史定位器核对、发布步骤和错误监控，以及本地 JSON / Markdown / HTML / ZIP 调试资料导出。

- 可暂停、继续、结束录制，添加说明、删除无关步骤、追加录制片段。主页面点击在跳转前立即记录；子框架采用无权限采样，快速跳转事件可能丢失。
- 发布监控记录真实操作开始、耗时、定位器和错误，共用原发布引擎，不另开未登录浏览器、不占用发布 debugger 连接。任务操作沿用授权、互斥与提交边界保护。
- 输入值、密码、Cookie、令牌、存储、请求头、任意 HTML 和本地文件路径不采集。截图默认关闭；开启后遮盖输入区、媒体、iframe 和非白名单文本，逐张确认或删除，再预览并导出。普通个人信息需自行排除和审阅，不保证自动识别全部隐私。
- 资料仅本地保存；关闭工具释放监听并保留原环境，异常退出后保留已保存报告并标记中断。账号隔离、品牌、导航折叠、启动地址锁定及发布保护继续沿用。

使用：打开已登录环境 → 左侧「开发」→ 连接环境 → 开始录制 → 在原窗口手动操作 → 结束 → 审阅截图与导出预览 → 导出 ZIP。详见[开发者工具指南](https://github.com/liu341567-sys/zhiwen/blob/main/docs/developer-tools.md)。

测试使用真实 Electron 与本地网页夹具；用户已登录的抖音创作者页面及真实发布流程仍需实机验证。尚不提供自动回放、自动生成脚本、闭合 Shadow DOM 读取或平台验证绕过。

- 修复未提交的失败 / 暂停尝试误计入账号发布间隔。实际提交后的最小间隔、账号互斥、并发限制和结果待核实保护继续有效；已删除且无法判断是否提交的旧版间隔记录仍保守保留。
- 待执行任务显示等待原因与可执行时间；日志在原因变化时记录，不再静默等待。详情显示调度器状态、最近检查时间及并发使用情况。
- 新增任务详情“本地运行诊断”：每 2 秒采集原环境的页面控件结构、可见 / 禁用状态、真实页面和原生视口尺寸、视频预览就绪状态、点击 / 输入 / 话题空格事件及执行阶段。支持人工接管过程中继续记录、阶段标记、刷新、停止、导出 JSON 和删除诊断。
- 诊断仅在主动开始后记录，最长 10 分钟；最多同时三个不同账号。每任务报告约 2 MiB、最多 300 个状态快照，保留最新状态。报告不保存输入内容、Cookie、账号名称、完整网址、页面 HTML 或截图，无自动网络上传；导出仅由用户选择保存路径。
- 原有素材 / 文案 / 封面 / 定位 / 任务记录删除、完整批次重置、启动配置锁定、导航折叠与账号隔离保持。删除任务同步清理其诊断；失败尝试的旧间隔记录可安全清理，实际发布间隔和最小去重信息保留。

正常退出旧版后安装更新。未提交的暂停任务可继续；已到提交边界的任务须先核实，不能直接重发。
