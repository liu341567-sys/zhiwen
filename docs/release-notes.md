# 栖页 0.3.15 · 本地运营数据中心（预览）

新增数据中心八个运营功能入口，按运营数据、分析与报表、采集管理分组，原私信汇总单独保留。一级双层导航、固定折叠偏好、账号环境和发布功能保持兼容。

账号采集使用原独立Session中的后台只读页面，入口为用户确认的抖音经营数据页，按需补充首页和作品管理页。新SQLite库保存账号、作品、指标定义、历史快照、采集任务、配置和日志。支持手动/批量采集、有限并发、定时调度、失败重试与取消、中断恢复检查、官方后台跳转、本地数据库备份。

页面提供账号及作品筛选、排序、分页、详情、粉丝/作品/获赞历史采集点趋势、同平台账号对比和Excel/CSV导出。有效指标记录来源、统计口径、时间和精度；失败保留旧值，缺失不补0，约数不算精确汇总，跨平台不混加流量。粉丝变化仅在存在可靠起点/终点时计算，周期指标必须有明确的官方日期范围且与筛选完全相同。

重要边界：真实抖音登录页面和账号权限尚待实页核验，无法确认的字段明确失败/部分成功。只读当前已加载作品，可靠作品ID才建记录；不承诺全量翻页、全量新增作品、缩略图、互动率、任意周期自动查询或所有平台指标。其他平台待适配。窗口夹具验证用于检验功能链路与隔离，不是官方页面数据验收。详见[数据中心指南](analytics.md)。

本地217项单元和语法检查已通过。Windows窗口、安装与公开下载验证完成后补充结果。
