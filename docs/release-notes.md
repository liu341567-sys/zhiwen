# 栖页 0.3.12 · 私信汇总预览

基于0.3.11继续开发，在“数据中心 → 私信汇总”增加本地多账号只读巡检、账号选择、间隔/并发设置、可靠基线持久化、数量变化聚合提醒、Windows通知及提示音、按环境ID查看官方消息、异常退避、脱敏诊断与数据库备份。

复用原账号Session，必要时使用临时后台列表页，不替换用户原网页，不点击会话、不发送或标记已读。与发布任务共享账号互斥，保留原有导航折叠、环境排序、启动网址锁定及登录数据。其他平台明确待适配，不伪造未读数。

支持读取抖音官方页面明确呈现的私信计数及已加载会话徽标。会话列表完整性未经证实时仅展示下界，完整总数待核实；如有稳定会话标识，仅在本机保存加盐摘要与计数以比较同一会话，不保存联系人或正文。首次有效巡检只建立基线，后续计数增加属于估算，不能断言真实新增条数；未知、冲突、超时及99+等上限计数不会当作零，也不会据此推进可靠基线。

**验证边界：**用户确认了创作者私信入口及“不点会话不会清零”。自动化测试使用合成网页验证架构、只读控制和异常处理；尚无该用户已登录抖音页面的DOM，官方计数识别标记为实页待核验。若显示“待核实”，可在该行“详情”导出不含消息正文与凭据的诊断文件。
