# 栖页 0.1.5 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 恢复 0.1.3 的侧栏蓝色选中块，使当前工作空间与账号环境更容易识别。
- 侧栏「新建环境」恢复实心蓝色按钮，并配套蓝色悬停和按下状态。
- 页面、欢迎区、卡片及其他组件继续采用 0.1.4 的中性配色。
- 修正鼠标操作环境后按 Shift 出现的额外焦点框，保留键盘导航的焦点提示。
- 取消编辑对话框后，将焦点恢复到对应环境的编辑按钮。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

下载 `Qiye-0.1.5-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.5-x64.exe` 安装，`SHA256SUMS.txt` 提供两份文件的 SHA256 校验值。更新前请正常退出旧版并备份整个 `%APPDATA%\栖页` 数据目录，已有账号环境继续沿用该目录。

原有 Logo、字体、布局、账号数据、会话隔离和登录流程继续沿用；真实知乎、抖音登录兼容性仍需实机验证。Windows 已通过 39 项单元、23 项隔离、16 项本地登录兼容性、语法和原生 DPAPI 恢复检查，以及三档设备缩放的 147 项实际窗口回归。NSIS 安装、PE 与快捷方式图标、已安装程序的数据恢复及卸载均通过。设备缩放由 Electron 设置并核对实际 DPR，未切换 Windows 设置面板的物理显示器 DPI。0.1.5 已公开发布，发布页与三个附件下载及 SHA256 校验文件已核实。本版本为未签名的试用版。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
