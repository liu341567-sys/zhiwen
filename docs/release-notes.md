# 栖页 0.1.2 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 统一浏览器标识：页面、iframe、弹窗和 Service Worker 的 JavaScript 与 HTTP 请求均使用同一标准网页 User-Agent，移除 `Qiye` / `Electron` 产品标识，保留真实系统描述、Chromium 完整版本及原生 Client Hints。
- 新增手动开启的知乎登录诊断：只针对选中的一个环境，最长记录 2 分钟，保存记录期间完成或失败的知乎请求统计、HTTP 状态、网络错误、可见 `10001` 提示布尔值及浏览器标识一致性结果。
- 修正集成测试启动方式：显式启用沙箱并移除测试工具对存储、密码库和弹窗等行为的默认改动，直接检查真实主框架的沙箱与上下文隔离状态。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

诊断操作：点击「登录诊断」后「开始记录」，对话框关闭后在网页手动执行一次登录；再次打开诊断，点击「保存报告」结束记录并保存本地 JSON。报告不含网址、路径、查询参数、请求头或正文、Cookie、手机号、输入值、页面正文、原始 User-Agent、环境 ID 或名称，不自动上传。

下载 `Qiye-0.1.2-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.2-x64.exe` 安装，`SHA256SUMS.txt` 提供两份文件的 SHA256 校验值。应用数据继续使用 `%APPDATA%\栖页`，更新前请正常退出应用并备份整个数据目录。

本地已通过 39 项单元测试、23 项隔离检查和 16 项登录兼容性检查。发布流程要求 Windows 上的单元测试、语法检查和真实 Chromium 检查全部通过后才生成发布文件。测试使用本地网页。用户已确认 0.1.1 中知乎扫码和手机验证码登录均出现 `10001`；云环境无法访问知乎，尚未确认该错误的原因，也没有证据证明真实知乎或抖音登录已成功。浏览器标识调整不改写登录请求参数或签名，不修改网页的 navigator 对象，也不关闭 TLS 校验。本版本为未签名的试用版。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
