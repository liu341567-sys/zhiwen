# 栖页 0.1.0 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 新建环境使用独立 Cookie、缓存及网站存储，可以分别登录不同账号。
- 支持环境名称、备注、颜色标记和同时打开多个环境。
- 关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。
- 登录弹窗沿用所属环境，关闭或退出一个账号不会清除其他环境的数据。

下载 `Qiye-0.1.0-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.0-x64.exe` 安装。`SHA256SUMS.txt` 提供两份下载文件的 SHA256 校验值。应用数据默认保存在 `%APPDATA%\栖页`。

本发布流程要求 Windows 上的单元测试、语法检查和真实 Chromium 会话隔离测试通过后才生成发布文件。测试使用本地网页；真实抖音登录、扫码和平台兼容性尚需实机验证。本版本是试用版，安装包没有代码签名。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。备份前请正常退出应用，再复制整个数据目录；Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
