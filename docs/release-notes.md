# 栖页 0.1.3 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 接入原版栖页图标与字标，统一应用界面、主窗口、弹窗、Windows 程序及安装 / 卸载图标；素材只整理透明边距和等比缩放，不重新绘制。
- 统一蓝色主色、深色标题与中性色层级，正文、按钮和输入框采用 14 px 字号，提升界面可读性。
- 标签名称与关闭按钮分区布局，长名称显示省略号，关闭区域保持固定；多个标签可以横向滚动，悬停和选中时不移动关闭按钮。
- 调整小工作区、显示缩放和对话框布局，初始窗口不超出可用桌面，对话框限制在视口内并支持滚动。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

下载 `Qiye-0.1.3-x64.zip` 后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载 `Qiye-Setup-0.1.3-x64.exe` 安装，`SHA256SUMS.txt` 提供两份文件的 SHA256 校验值。更新前请正常退出旧版并备份整个 `%APPDATA%\栖页` 数据目录，已有账号环境继续沿用该目录。

本次为视觉与品牌更新，账号数据、会话隔离和登录流程沿用原有实现；真实知乎、抖音登录兼容性仍需实机验证。发布验收要求单元、语法、真实浏览器隔离与登录兼容性检查，并检查多种显示缩放下的布局、Windows 程序图标资源及安装后的图标与快捷方式。这些检查完成后再交付安装包。本版本为未签名的试用版。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
