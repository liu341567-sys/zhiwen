# 栖页 0.1.6 · Windows 试用版

用于在同一台 Windows 10 / 11（64 位）电脑上管理多个短视频平台账号。

- 新建及编辑环境支持九个平台预设，以 3 × 3 选项直接选择创作者中心入口。
- 环境保存所选平台，选择项、侧栏与账号卡片使用对应平台图标；改名后继续保留关联。
- 同一平台可以新建多个独立环境，各账号继续使用各自的 Cookie 和网站存储。
- 支持自定义网址；编辑切换平台只更新启动入口，重新打开仍恢复上次页面和原有会话数据。

各环境仍使用独立 Cookie、缓存及网站存储，支持名称、备注和同时打开。关闭标签页保留环境；重新打开及重启应用继续使用原会话数据，登录能否延续取决于平台有效期。

下载 [ZIP 版](https://github.com/liu341567-sys/zhiwen/releases/download/v0.1.6/Qiye-0.1.6-x64.zip)后完整解压，运行目录中的 `栖页.exe`；不要只复制 exe。也可下载[安装版](https://github.com/liu341567-sys/zhiwen/releases/download/v0.1.6/Qiye-Setup-0.1.6-x64.exe)，[SHA256SUMS.txt](https://github.com/liu341567-sys/zhiwen/releases/download/v0.1.6/SHA256SUMS.txt)提供两份文件的校验值。更新前请正常退出旧版并备份整个 `%APPDATA%\栖页` 数据目录，已有账号环境继续沿用该目录。

Windows 已通过 59 项单元、语法、23 项隔离、16 项本地登录兼容性、原生 DPAPI 及 201 项实际窗口检查；实际安装后的九平台图标、关联恢复、账号测试数据恢复及卸载也通过。设备缩放为 Electron 实际 DPR，未切换 Windows 物理显示器 DPI。0.1.6 已公开发布，发布页与三个附件下载及校验文件已核实。本次增加入口与环境标识，真实平台登录仍需实机复测。本版本为未签名的试用版。

环境共享当前电脑和网络出口，不提供代理或指纹伪装。Cookie 加密与 Windows 用户绑定，跨电脑迁移可能需要重新登录。
