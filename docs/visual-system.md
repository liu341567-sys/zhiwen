## 平台预设与图标

新建对话框的 `#platform-presets` 采用固定三列，九项始终以 3 × 3 显示。每项为同组单选按钮，展示配置中的本地平台图标和名称；图标为 24 × 24 px、等比容纳，名称保持 14 px。选中状态复用侧栏的 `#edf4ff` / `#c8dcfb`，悬停选中项使用 `#e3eefe`，键盘焦点使用现有焦点色。

「自定义网址」属于同一单选组，新建时默认选中；只有自定义模式显示可编辑网址输入框。已建环境编辑时显示已保存的启动配置，平台、网址类型及启动网址均只读，名称、备注及颜色保持可编辑。首次使用启动入口、重开恢复上次页面的说明在两种模式下都保持可见。对话框继续受视口限制并内部滚动，小窗口保持九项可用与原字号。

平台图标用于选择项、侧栏和账号卡片。侧栏及卡片在图片加载成功后替换默认首字母图标，失败保留默认图标；选择项失败时保留平台名称和文字备用标记。标签页继续使用原有颜色标记和固定关闭区域。旧环境及自定义环境使用原默认图标，不按域名推断平台。九份本地资源保留镜像中的原始 SVG、WEBP、PNG 或 ICO 字节，来源与摘要见[图标清单](../branding/platform-assets.json)，配置和核验边界见 [平台预设说明](platform-presets.md)。

## 标签页

环境标签使用 `minmax(0, 1fr) 30px` 两列布局：可收缩的名称区域与固定宽度的关闭区域。标签最小宽度 156 px、最大宽度 224 px；关闭按钮为 30 × 30 px，图标为 15 × 15 px。名称区域设置 `min-width: 0`、单行省略号和溢出裁剪，关闭区域独立占位。工作空间标签为 132 px 单列布局，不带关闭按钮。

名称变化、悬停、选中或失去选中状态不能改变关闭区域的几何位置。状态变化通过色彩与边框表达，保留原有关闭、新建、切换操作。标签数量超过可用宽度时，标签列表横向滚动，不把每个标签压缩到无法操作。

## 侧栏拖拽排序

拖拽只作用于「我的环境」列表。鼠标左键按下后移动超过 8 px 才进入排序状态，未达到阈值时保持原有点击行为；编辑按钮不作为拖拽入口。拖动项采用轻微透明度反馈，预计位置使用品牌蓝色插入线，不改变原行尺寸、平台图标、名称、当前选中状态或点击区域。

拖到列表顶部或底部边缘时自动滚动，释放后保存新顺序；取消拖动不提交。显示顺序使用既有 `profiles` 数组记录，不增清单字段，不重写环境记录。顶部已打开标签继续按原有打开顺序，工作空间卡片继续按创建时间排序。页面切换和程序重启后恢复已保存的侧栏顺序。

普通滚轮或 Shift + 滚轮不启动拖拽、不改变顺序或当前环境，拖动过程不将经过的环境选中。键盘焦点继续采用既有输入来源策略，表单与导航键可访问性保留。

## 环境操作与焦点

真实 Electron 复现中，鼠标点击侧栏或工作空间操作后，单独按下 Shift 就会触发原生 `:focus-visible` 启发式的额外焦点轮廓，无需滚轮；滚动和鼠标移动未改变当前环境。卡片的悬停与单个按钮焦点也需要和当前账号状态区分。

界面通过根元素的 `data-environment-focus` 记录输入来源：`pointerdown` 表示鼠标等指针操作，Tab、Enter、Space、方向键、Home / End、PageUp / PageDown 和 Escape 等导航键切换到键盘模式；Shift 等修饰键自身不切换模式。仅对鼠标来源的环境操作按钮抑制额外轮廓，包括环境行、卡片、标签、新建、工作空间及新标签按钮。全局原生焦点、表单焦点和文字选择继续保留；滚轮和 Shift 不被禁用，也不通过 `preventDefault` 改写行为。

对话框开启前保存逻辑 `data-focus-key`，关闭后按该键匹配重新渲染的按钮，恢复原编辑按钮焦点，避免旧 DOM 失效后回退到其他控件。

## 窗口、缩放与对话框

Electron 窗口尺寸使用可用工作区的 DIP；页面布局使用 CSS 逻辑像素，不额外手工乘以系统缩放倍数。

| 项目 | 规则 |
| --- | --- |
| 初始窗口 | 宽 `min(1440, 工作区宽)`，高 `min(940, 工作区高)` |
| 最小窗口 | 宽 `min(900, 工作区宽)`，高 `min(600, 工作区高)` |
| 页面布局 | 移除固定 1020 × 700 最小页面限制；小工作区按 900 × 480 的内容视口检查 |
| 标签列表 | 横向滚动，名称省略；新增按钮与关闭区域保持可操作 |
| 对话框 | 默认宽 480 px，最大宽 `视口宽 − 32px`，最大高 `视口高 − 32px`，内容超出时内部滚动 |

新建环境对话框只有右上角「×」作为主动关闭入口：背景点击与 Escape 不关闭，隐藏原取消按钮；表单校验和创建成功后自动关闭的逻辑保持。编辑、删除等其他对话框保留原关闭方式。

小窗口优先保留环境列表、标签、导航和表单操作。文字与品牌图片保持比例；较长的说明、备注及诊断报告通过换行或滚动显示。100%、125%、150% 显示缩放属于验证范围，不能仅根据 CSS 声明推断实际 Windows 表现。

响应式规则以内容视口宽高判断：

| 条件 | 布局调整 |
| --- | --- |
| 宽度 ≤ 1180 px | 侧栏缩至 248 px，减少间距，隐藏标签栏辅助文字 |
| 宽度 ≤ 1040 px | 侧栏缩至 232 px，隐藏欢迎装饰和地址栏附加环境说明 |
| 宽度 ≤ 820 px | 侧栏缩至 218 px，功能说明改为单列，压缩导航间距 |
| 宽度 ≤ 640 px | 侧栏缩至 196 px，地址栏独占一行，标题与卡片操作允许换行 |
| 高度 ≤ 700 px | 缩减顶部和欢迎区域间距 |
| 高度 ≤ 550 px | 侧栏允许滚动，限制环境列表和底部信息区高度，隐藏欢迎装饰 |
