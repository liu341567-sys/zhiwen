# 栖页 0.1.4 视觉规范

0.1.4 调整全局配色、组件状态颜色与原生窗口初始背景。原图、字标、字体、页面结构及几何规范沿用 0.1.3；账号环境清单、Cookie 加密存储、会话分区、预加载脚本、导航、登录标识及运行引擎继续使用原有实现。测试状态以 [验证记录](validation.md) 和实际工作流结果为准，下方 0.1.3 的历史结果不代表 0.1.4 已验证。

## 品牌素材

品牌使用用户提供的两份原始 PNG。原图保存在 `branding/originals`，来源摘要、裁剪区域和输出规格记录在 [素材清单](../branding/assets.json)。不重新绘制图形或字标，不改变原图颜色；仅裁去透明边缘及 Alpha 最多为 1 的几乎透明像素，再按原图比例处理。

| 用途 | 原始素材 | 应用素材 | 规格 |
| --- | --- | --- | --- |
| 应用图形 | `branding/originals/desktop.png`，1254 × 1254 | `src/assets/qiye.png` | 512 × 512 透明画布，图形等比拟合到最大 432 × 432 区域并居中 |
| 界面字标 | `branding/originals/wordmark.png`，1672 × 941 | `src/assets/qiye-wordmark.png` | 保留原字标，整理边距后 1253 × 559，显示时等比缩放 |
| Windows 图标 | 同一应用图形 | `src/assets/qiye.ico` | 32 位 RGBA / DIB，包含 16、20、24、32、40、48、64、128、256 px 九种尺寸 |

原始图形 SHA256 为 `f6c660f2b7732c27db0cdf312d5f60b1fb27dad16aec5a7d31364dc6d497a878`；原始字标为 `c84549533eb039cc075d0fd23a606319b3fa07e31b2b25b9ab38e4322d203e58`。它们用于核对素材来源，不是安装包的校验值。

主界面使用原图与字标。主窗口和网页弹窗使用同一应用图标。打包时将 `qiye.ico` 与 `qiye.png` 另放于 `resources/brand-icons`，供原生窗口从实际文件路径读取；界面内的图片随 `src` 资源打包。

Windows 程序的 PE 图标资源、NSIS 安装器及卸载器采用同一 ICO。`win.signExecutable: false` 只禁用签名，保留可执行文件图标资源编辑。应用 `appId` 与 AppUserModelID 均使用 `com.qiye.browser`，安装快捷方式继续显示名称「栖页」。

## 色彩与字体

配色按区域职责分配：中性灰承载页面、侧栏和浏览器工具栏，白色表面承载欢迎区、卡片与对话框，品牌蓝强调主操作、选中标记和键盘焦点。色彩层次通过表面、边框和状态区分，不使用固定的颜色面积比例。

| 层级 | 规范 |
| --- | --- |
| 主色 | `--brand: #1f5fca`，悬停 `--brand-hover: #1953b4`，按下 `--brand-active: #164795` |
| 品牌浅色与边框 | `--brand-light: #f0f3f9`，`--brand-border: #ccd8eb` |
| 键盘焦点 | `--focus: #5b87c7`，焦点光晕 `--focus-halo: #1f5fca14` |
| 页面与原生窗口初始背景 | `--background: #f4f5f7`，原生窗口初始背景使用同值 |
| 侧栏 | `--sidebar-surface: #f8f9fb` |
| 标签栏 | `--chrome-surface: #eef0f3` |
| 导航栏 | `--navigation-surface: #fafbfc` |
| 欢迎区、卡片与对话框 | `--surface: #ffffff` |
| 内嵌表面 | `--surface-inset: #f5f6f8` |
| 中性悬停、按下与选中 | `--surface-hover: #eceff3`，`--surface-pressed: #e5e9ef`，`--surface-selected: #e9edf2` |
| 主要文字 | `--text: #202938` |
| 辅助文字 | `--secondary: #515c6c`，次级提示 `--muted: #5e6a7b` |
| 边框 | `--line: #e2e6ec`，强调边框 `--line-strong: #cbd2dc`，悬停边框 `--line-hover: #b8c1cd` |
| 危险操作 | `--danger: #b33d43`，悬停 `#963139`，按下 `#7e2930`；浅色反馈 `#faf3f3`、边框 `#e7cdd0` |
| 正文、常规按钮、输入框 | `--font-body: 14px` |
| 辅助说明与状态信息 | `--font-small: 12px` |
| 标题 | `--font-title: 18px` / `--font-heading: 24px` / `--font-hero: 32px` |

侧栏「新建环境」按钮采用白色表面、深色文字和中性边框，图标保留品牌蓝；悬停及按下使用统一中性状态表面。选中的环境与工作空间使用中性底色并保留细蓝色标记。危险操作使用独立红色状态，错误反馈以文字和局部标记突出。

环境编辑图标使用 `--muted` 与 `opacity: 0.85`，所在行悬停或获得焦点时不透明度为 `1`。

六种环境识别色的 `--profile-accent` 保持原值：橙 `#e87941`、蓝 `#658ac0`、绿 `#5b8d79`、紫 `#9473b5`、粉 `#ca7181`、金 `#c39c49`。环境图标的浅色背景减弱，首字母使用主要深色文字；颜色标记仍用于识别账号。

全局字号通过样式变量复用。系统字体顺序覆盖 Windows 的 Segoe UI / Microsoft YaHei 和其他平台的系统中文字体。按钮、输入框及文本框继承字体；使用颜色、字重和间距表达层级，避免各组件自行缩小文字。

## 标签页

环境标签使用 `minmax(0, 1fr) 30px` 两列布局：可收缩的名称区域与固定宽度的关闭区域。标签最小宽度 156 px、最大宽度 224 px；关闭按钮为 30 × 30 px，图标为 15 × 15 px。名称区域设置 `min-width: 0`、单行省略号和溢出裁剪，关闭区域独立占位。工作空间标签为 132 px 单列布局，不带关闭按钮。

名称变化、悬停、选中或失去选中状态不能改变关闭区域的几何位置。状态变化通过色彩与边框表达，保留原有关闭、新建、切换操作。标签数量超过可用宽度时，标签列表横向滚动，不把每个标签压缩到无法操作。

## 窗口、缩放与对话框

Electron 窗口尺寸使用可用工作区的 DIP；页面布局使用 CSS 逻辑像素，不额外手工乘以系统缩放倍数。

| 项目 | 规则 |
| --- | --- |
| 初始窗口 | 宽 `min(1440, 工作区宽)`，高 `min(940, 工作区高)` |
| 最小窗口 | 宽 `min(900, 工作区宽)`，高 `min(600, 工作区高)` |
| 页面布局 | 移除固定 1020 × 700 最小页面限制；小工作区按 900 × 480 的内容视口检查 |
| 标签列表 | 横向滚动，名称省略；新增按钮与关闭区域保持可操作 |
| 对话框 | 默认宽 480 px，最大宽 `视口宽 − 32px`，最大高 `视口高 − 32px`，内容超出时内部滚动 |

小窗口优先保留环境列表、标签、导航和表单操作。文字与品牌图片保持比例；较长的说明、备注及诊断报告通过换行或滚动显示。100%、125%、150% 显示缩放属于验证范围，不能仅根据 CSS 声明推断实际 Windows 表现。

响应式规则以内容视口宽高判断：

| 条件 | 布局调整 |
| --- | --- |
| 宽度 ≤ 1180 px | 侧栏缩至 248 px，减少间距，隐藏标签栏辅助文字 |
| 宽度 ≤ 1040 px | 侧栏缩至 232 px，隐藏欢迎装饰和地址栏附加环境说明 |
| 宽度 ≤ 820 px | 侧栏缩至 218 px，功能说明改为单列，压缩导航间距 |
| 宽度 ≤ 640 px | 侧栏缩至 196 px，地址栏独占一行，标题与卡片操作允许换行 |
| 高度 ≤ 700 px | 缩减顶部和欢迎区域间距 |
| 高度 ≤ 550 px | 侧栏允许滚动，限制环境列表和底部信息区高度，隐藏欢迎装饰 |

## 验证范围

视觉验收需要在真实 Electron 中检查短名称、长中文名称、多个标签、悬停和选中切换、关闭按钮位置、小工作区及对话框滚动。Windows 验收还需检查已打包程序、实际安装后的主程序、安装器和卸载器的 PE 图标资源，以及桌面快捷方式与运行窗口图标。
