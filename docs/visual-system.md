# 栖页 0.1.11 视觉规范

沿用 0.1.10 分离全局模块导航与账号列表的架构。一级导航固定 64 px，二级侧栏固定 240 px，主区填满剩余宽度。一级栏使用附件竖版原图；14 px 正文、12 px 辅助信息、品牌蓝选中块和实心主按钮保持，不开发未来发布业务。实际检查状态见 [验证记录](validation.md)。

## 导航层级与状态

一级竖向图标导航包含环境、发布、数据、AI 工具和固定底部的设置；选中使用品牌蓝实心块，未选中使用中性色，悬停浅蓝。一级功能独立滚动，增添菜单不改变账号列表高度。二级环境侧栏复用原账号列表、搜索、新建、编辑、排序和平台图标节点；仅列表滚动，头部与搜索保持稳定，底部说明可独立滚动。

标准模式占据 240 px；一级栏底部同一个固定按钮负责展开 / 收起，标签、图标及悬停提示随状态更新。二级侧栏和设置正文不再有重复的折叠入口。普通点击一级入口只切换模块，保持原折叠偏好，收起后不闪现或自动呼出侧栏。只有右键一级入口或聚焦后使用菜单键 / Shift + F10，才主动呼出临时覆盖侧栏；覆盖不改变主区尺寸。右上角关闭、外部点击、Escape、固定收起按钮或成功选择账号后关闭临时覆盖，不改固定折叠偏好。内容发布的五个菜单及数据、AI 子项均禁用并标记「规划中」，主区提供说明与返回环境管理按钮，不进入空白页。设置只管理布局、查看既有数据位置及打开既有环境编辑。

宽度低于 640 px 时自动使用收起 / 覆盖模式，保留用户的标准布局偏好；放大窗口后恢复该偏好。在窄窗口下，固定按钮主动打开或关闭覆盖层，普通导航点击仍不呼出侧栏。覆盖层约 160 ms 淡入，支持减少动画偏好。导航模块及菜单统一配置于 `src/navigation-modules.json`；界面偏好独立保存为 `ui-preferences.json`，不改变 `profiles.json`。保存模块、折叠、搜索、账号及模块滚动位置、窗口普通尺寸及最大化状态；临时浮层不会跨启动保存。正常退出前再保存最后一次操作位置。

原生网页会覆盖普通 HTML 浮层。临时覆盖时显示当前网页的内存画面并暂时隐藏原视图，网页实例与尺寸仍保留，关闭后恢复实时页面；画面不落盘、不上传，并在关闭覆盖层时清除。不同业务模块切换只改变可见性，浏览器环境继续运行。顶部 Toast 继续浮于原生网页之上，不占用侧栏空间。

## 平台预设与图标

新建对话框的 `#platform-presets` 采用固定三列，九项始终以 3 × 3 显示。每项为同组单选按钮，展示配置中的本地平台图标和名称；图标为 24 × 24 px、等比容纳，名称保持 14 px。卡片最小高度 48 px、行列间距 6 px、上下内边距 8 px。选中状态复用侧栏的 `#edf4ff` / `#c8dcfb`，悬停选中项使用 `#e3eefe`，键盘焦点使用现有焦点色。

「自定义网址」属于同一单选组，新建时默认选中；只有自定义模式显示可编辑网址输入框，切换平台后再返回时保留自定义草稿。已建环境编辑时显示已保存的启动配置，平台、网址类型及启动网址均只读，名称、备注及颜色保持可编辑。首次使用启动入口、重开恢复上次页面的说明在两种模式下都保持可见。九项预设与原字号在小窗口中保持，滚动仅限中间表单。

平台图标用于选择项、侧栏和账号卡片。侧栏及卡片在图片加载成功后替换默认首字母图标，失败保留默认图标；选择项失败时保留平台名称和文字备用标记。标签页继续使用原有颜色标记和固定关闭区域。旧环境及自定义环境使用原默认图标，不按域名推断平台。九份本地资源保留镜像中的原始 SVG、WEBP、PNG 或 ICO 字节，来源与摘要见[图标清单](../branding/platform-assets.json)，配置和核验边界见 [平台预设说明](platform-presets.md)。

## 标签页

环境标签使用 `minmax(0, 1fr) 30px` 两列布局：可收缩的名称区域与固定宽度的关闭区域。标签最小宽度 156 px、最大宽度 224 px；关闭按钮为 30 × 30 px，图标为 15 × 15 px。名称区域设置 `min-width: 0`、单行省略号和溢出裁剪，关闭区域独立占位。工作空间标签为 132 px 单列布局，不带关闭按钮。

名称变化、悬停、选中或失去选中状态不能改变关闭区域的几何位置。状态变化通过色彩与边框表达，保留原有关闭、新建、切换操作。标签数量超过可用宽度时，标签列表横向滚动，不把每个标签压缩到无法操作。

## 侧栏拖拽排序

拖拽只作用于「我的环境」列表。鼠标左键按下后移动超过 8 px 才进入排序状态，未达到阈值时保持原有点击行为；编辑按钮不作为拖拽入口。拖动项采用轻微透明度反馈，预计位置使用品牌蓝色插入线，不改变原行尺寸、平台图标、名称、当前选中状态或点击区域。

拖到列表顶部或底部边缘时自动滚动，释放后保存新顺序；取消拖动不提交。显示顺序使用既有 `profiles` 数组记录，不增清单字段，不重写环境记录。顶部已打开标签继续按原有打开顺序，工作空间卡片继续按创建时间排序。页面切换和程序重启后恢复已保存的侧栏顺序。

普通滚轮或 Shift + 滚轮不启动拖拽、不改变顺序或当前环境，拖动过程不将经过的环境选中。键盘焦点继续采用既有输入来源策略，表单与导航键可访问性保留。

## 环境操作与焦点

真实 Electron 复现中，鼠标点击侧栏或工作空间操作后，单独按下 Shift 就会触发原生 `:focus-visible` 启发式的额外焦点轮廓，无需滚轮；滚动和鼠标移动未改变当前环境。卡片的悬停与单个按钮焦点也需要和当前账号状态区分。

界面通过根元素的 `data-environment-focus` 记录输入来源：`pointerdown` 表示鼠标等指针操作，Tab、Enter、Space、方向键、Home / End、PageUp / PageDown 和 Escape 等导航键切换到键盘模式；Shift 等修饰键自身不切换模式。仅对鼠标来源的环境操作按钮抑制额外轮廓，包括环境行、卡片、标签、新建、工作空间及新标签按钮。全局原生焦点、表单焦点和文字选择继续保留；滚轮和 Shift 不被禁用，也不通过 `preventDefault` 改写行为。

对话框开启前保存逻辑 `data-focus-key`，关闭后按该键匹配重新渲染的按钮，恢复原编辑按钮焦点，避免旧 DOM 失效后回退到其他控件。

## 窗口、缩放与对话框

Electron 窗口尺寸使用可用工作区的 DIP；页面布局使用 CSS 逻辑像素，不额外手工乘以系统缩放倍数。

| 项目 | 规则 |
| --- | --- |
| 初始窗口 | 宽 `min(1440, 工作区宽)`，高 `min(940, 工作区高)` |
| 最小窗口 | 宽 `min(900, 工作区宽)`，高 `min(600, 工作区高)` |
| 页面布局 | 移除固定 1020 × 700 最小页面限制；小工作区按 900 × 480 的内容视口检查 |
| 标签列表 | 横向滚动，名称省略；新增按钮与关闭区域保持可操作 |
| 环境创建 / 编辑弹窗 | 保留 480 px 默认宽，最大宽 `视口宽 − 32px`，最大高 `min(88dvh, 100dvh − 32px)`；外层不滚动 |
| 其他对话框 | 沿用原尺寸限制及滚动方式 |

环境弹窗使用纵向 Flex 布局。`#profile-dialog-header` 和 `#profile-dialog-footer` 不收缩，中间 `#profile-dialog-body` 使用 `min-height: 0` 与 `overflow-y: auto`，只有该区出现滚动条；外层弹窗和表单壳不滚动。顶部将图标、24 px 标题与 40 × 40 px 关闭按钮放在同一行，辅助说明置于其下。底部以浅分割线与表单分隔，原蓝色主操作始终靠右。打开后表单回到顶部并聚焦环境名称，表单滚动到末端时隔离说明完整显示在底部栏上方。

表单模块通常保留 12 px 下间距，平台与颜色模块 14 px，备注最小高度 64 px；14 px 正文、按钮、输入框和预设文字字号保持。预设平台时收起自定义输入区。原生必填项和应用网址校验失败时，滚动中间区域并聚焦首个需修正字段；应用错误文字位于固定底部栏，并通过 `aria-invalid` / `aria-errormessage` 关联字段，输入后清除。

中间区域采用 `overscroll-behavior: contain`；滚轮位于标题栏、底部栏或弹窗外侧时不滚动表单与背景。新建环境对话框只有右上角「×」作为主动关闭入口：背景点击与重复 Escape 不关闭，隐藏原取消按钮；创建成功后按原流程关闭。共用编辑弹窗沿用取消、删除与 Escape 操作，删除等其他对话框的关闭方式保持。

小窗口优先保留环境列表、标签、导航和表单操作。文字与品牌图片保持比例；较长的说明、备注及诊断报告通过换行或滚动显示。100%、125%、150% 显示缩放属于验证范围，不能仅根据 CSS 声明推断实际 Windows 表现。

响应式规则以内容视口宽高判断：

| 条件 | 布局调整 |
| --- | --- |
| 全部宽度 | 一级导航固定 64 px，二级侧栏固定 240 px；收起时只保留一级导航 |
| 宽度 ≤ 1180 px | 隐藏标签栏辅助文字，减少工作区间距；导航宽度不变 |
| 宽度 ≤ 1040 px | 隐藏欢迎装饰和地址栏附加环境说明；导航宽度不变 |
| 宽度 ≤ 820 px | 功能说明改为单列，压缩浏览器工具栏间距；导航宽度不变 |
| 宽度 < 640 px | 二级侧栏自动改为临时覆盖，不覆盖用户保存的展开偏好；地址栏独占一行，标题与卡片操作允许换行 |
| 高度 ≤ 700 px | 缩减顶部和欢迎区域间距 |
| 高度 ≤ 550 px | 紧凑显示侧栏品牌与间距，环境列表独立滚动、底部信息区限制高度并独立滚动；外层侧栏不滚动，隐藏欢迎装饰 |

## 验证范围

视觉验收需要在真实 Electron 中检查短名称、长中文名称、多个标签、悬停和选中切换、关闭按钮位置、小工作区及对话框滚动。Windows 验收还需检查已打包程序、实际安装后的主程序、安装器和卸载器的 PE 图标资源，以及桌面快捷方式与运行窗口图标。

### 0.1.11 当前验证

本轮导航验收覆盖竖版原图比例与居中、原容器移除、完整新标题、唯一固定按钮及状态提示、所有模块在收起状态下切换且不闪现、主动临时覆盖、列表 / 图标 / 网页实例与滚动保留、重启恢复及窄窗口。本地完整入口通过 432 项既有 UI、51 项列表及 45 项导航检查；两条 Windows 工作流通过 357 项既有 UI、51 项列表及 45 项导航检查，实际 NSIS 安装 / 重启 / 卸载通过。三档均核对 Electron 实际 DPR；真实平台登录与 Windows 物理显示器 DPI 未验证。证据见 [验证记录](validation.md)，以下为历史。
